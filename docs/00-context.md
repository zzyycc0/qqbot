# 项目背景与设计摘要

本文保存与重建直接相关的项目目标和技术决策。旧环境的服务器地址、账号、费用、机器配置、用户标识、运行时配置和完整历史操作记录不放入公开 Git。

## 目标

在 QQ 私聊中提供具有连续人格、长期记忆和日常陪伴能力的 AI 角色。Windows 控制台用于管理远端服务、登录、日志、备份和迁移；运行数据保存在服务器并由所有者单独备份。

## 当前归档架构

- 服务器使用 Ubuntu、systemd 和原生进程管理。
- Linux QQ 与 NapCat 负责 QQ 接入；AstrBot 负责消息和插件。
- 陪伴插件与记忆插件负责角色互动、主动陪伴和长期记忆。
- Python 网关为模型访问提供统一接口、路由、用量记录和预算约束。
- Windows Electron 控制台通过 SSH 管理服务器并查看面板。
- 早期自研生活系统留在 `life-engine/` 作为开发参考，不是当前运行基线。

## 设计原则

1. 新实例从干净配置开始，不恢复历史聊天、记忆或 QQ 登录态。
2. 管理界面和内部服务只通过本机回环接口或 SSH 隧道访问。
3. 模型凭据、服务器连接信息、QQ 用户标识和运行数据只保存在实例所有者控制的环境中。
4. 模型使用量应由网关记录并设置明确上限；真实模型请求可能产生费用。
5. 角色提示词与示例内容应由所有者审核，不将个人聊天资料复制到公开仓库。
