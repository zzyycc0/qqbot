# 陪伴插件使用指南

本指南概述固定版本的陪伴与记忆插件常见页面。具体页面名称和选项会随上游版本变化；安装后以插件自带文档和面板说明为准。本文件不保留旧实例的用户绑定或设置值。

## 打开管理面板

使用 Windows 控制台中的陪伴面板入口。控制台通过 SSH 建立本地隧道后打开面板；访问令牌只保存在本机和服务器，不写入 Git。首次访问时按面板要求完成认证。

## 常见功能

| 页面或功能 | 用途 |
|---|---|
| 总览 | 查看插件状态、近期活动和协作组件 |
| 世界知识 / 角色 | 编辑角色背景、说话方式、关系设定和引用资料 |
| 私聊 | 配置目标用户的称呼、表达风格与互动规则 |
| 群聊 | 配置群聊接入；不使用时保持关闭 |
| 记忆 | 查看记忆采集、召回和插件协作设置 |
| 主动 | 设置主动行为来源、安静时段、频率和审计 |
| Token / 模型 | 查看用量并为任务选择模型服务 |
| 配置 / 排障 | 检查插件功能开关、依赖和连接状态 |
| 实验与外部能力 | 管理未稳定或涉及更多外部数据的功能 |

## 首次配置顺序

1. 确认角色提示词由实例所有者审核，避免加入聊天记录或个人隐私。
2. 设置新的目标用户绑定，并确认消息只发给预期联系人。
3. 配置模型地址、密钥和预算；先检查配置，不要用真实请求盲测。
4. 保持主动消息、群聊、语音、图像和外部工具等可选能力关闭，按需要逐项启用。
5. 确认记忆采集范围、保留方式和备份位置。
6. 在排障页面检查生效配置和依赖状态。

## 改动未生效时

有些插件会根据预设覆盖手动数值，另一些设置会在下一次消息或调度周期才更新。检查面板中的最终生效值，并查看插件文档说明；不要直接编辑运行中的服务器 JSON 来绕过面板。

## 日常维护

定期检查插件告警、模型用量、主动消息审计和备份结果。控制台或面板显示的“已连接”只说明该次检查结果，不能替代服务器和账号的完整状态核对。
